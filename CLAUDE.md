# vuelofloral.cl — тема Shopify (Dawn / Craft)

Магазин цветов по стеблю. Shopify CLI нет: файлы вручную копируются из редактора кода
админки, тема в репозитории НЕ полная. Если файл ссылается на сниппет, секцию, ассет или
локаль, которых нет в папке, — не угадывать содержимое, а выписать список недостающих
файлов и попросить докопировать.

Перед работой по пункту ТЗ читай docs/task-*.md

## Правила работы

1. Один пункт ТЗ = один коммит. Сообщение коммита: `C<N>: <что сделано>` (например `C1: ...`).
2. Перед первой правкой любого файла он уже должен быть в git как baseline (закоммичен
   в исходном виде из админки). Если файла нет в git — остановиться и сказать об этом.
3. Менять только файлы, нужные для текущего пункта ТЗ. `templates/*.json` правятся ещё и
   визуальным редактором Shopify — перед их правкой спрашивать пользователя.
4. Испанские тексты из ТЗ вставлять дословно. Плейсхолдеры вида `[X]`, `$X`, `$Y` не
   заполнять — оставлять как есть.
5. Только Liquid / CSS / JS темы. Никаких новых приложений.
6. После каждого коммита — выдать список изменённых файлов (путь в теме), чтобы
   пользователь вставил их обратно в админку.
7. Отвечать по-русски.

## Минимальный заказ 28.000 CLP — одно значение в нескольких местах

Порог проверяет приложение Melon Order Limits (правило на весь заказ, настраивается в админке
приложения). Тема его не читает, а дублирует. При смене порога менять во всех местах, иначе
прогресс на карточке и в корзине начнёт врать:
1. Приложение Melon Order Limits — правило минимальной суммы заказа.
2. `snippets/min-order-progress.liquid` — `min_order_threshold` (в сотых: 28.000 CLP = `2800000`).
3. Текст вкладки «Información adicional» («El monto mínimo de compra es de $28.000 CLP…») в
   `templates/product.template-1.json`, `product.template-2-short.json`, `product.template-decor.json`
   — правится в визуальном редакторе Shopify (или в JSON — только после согласования).
4. Объявление «Pedido minimo desde 28.000 más despacho» — announcement bar в шапке
   (`sections/header-group.json`, в репо нет), правится в визуальном редакторе.
